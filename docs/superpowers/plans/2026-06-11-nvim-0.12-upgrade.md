# Neovim 0.12 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Upgrade the nvim config to Neovim 0.12 by replacing nvim-cmp and 9 companion plugins with native built-in completion, and fixing all breaking changes.

**Architecture:** Four files change: `plugin-manager.lua` (one-line deprecation fix), `autocmds.lua` (remove dead autocmd), `lsp.lua` (remove cmp capability wiring, update fidget, add LspAttach for native completion), and `completion.lua` (full rewrite — drop nvim-cmp block, add completeopt + keybindings + mini.pairs). All changes are on branch `feat/nvim-0.12-upgrade`.

**Tech Stack:** Neovim 0.12, lazy.nvim, `vim.lsp.completion` (built-in), `mini.pairs` (from already-installed `mini.nvim`)

## Task 4: Rewrite completion.lua

**Files:**
- Modify: `nvim/.config/nvim/lua/plugins/completion.lua`

Replace the entire nvim-cmp block (everything after the codecompanion spec, lines 53–176) with:
- Global `completeopt` options for native completion
- Insert-mode keybindings for pum navigation (Tab, S-Tab, CR, C-Space)
- `mini.pairs` setup (autopairs replacement from already-installed `mini.nvim`)
- Keep copilot.vim and codecompanion blocks; remove `hrsh7th/nvim-cmp` from codecompanion's deps

`completeopt` flags used:
- `menu,menuone` — always show the popup menu
- `noinsert` — don't insert text as you navigate the menu
- `noselect` — don't pre-select any item (replicates nvim-cmp's `select = false`)
- `fuzzy` — new in 0.12, improves match ranking

The `<CR>` mapping: if pum is visible AND an item has been explicitly selected (`complete_info()['selected'] ~= -1`), confirm it with `<C-y>`; otherwise insert a normal newline. This is identical to the old nvim-cmp `cmp.mapping.confirm({ select = false })` behaviour.

The `<C-Space>` mapping triggers completion via `<C-x><C-o>` (omnifunc). `vim.lsp.completion.enable()` sets `omnifunc` to the LSP handler for the buffer, so this reliably triggers LSP completion.

- [ ] **Step 1: Rewrite completion.lua**

Replace the entire contents of `nvim/.config/nvim/lua/plugins/completion.lua` with:

```lua
vim.o.completeopt = 'menu,menuone,noinsert,noselect,fuzzy'

vim.keymap.set('i', '<Tab>', function()
  return vim.fn.pumvisible() == 1 and '<C-n>' or '<Tab>'
end, { expr = true, silent = true })

vim.keymap.set('i', '<S-Tab>', function()
  return vim.fn.pumvisible() == 1 and '<C-p>' or '<S-Tab>'
end, { expr = true, silent = true })

vim.keymap.set('i', '<CR>', function()
  if vim.fn.pumvisible() == 1 and vim.fn.complete_info()['selected'] ~= -1 then
    return '<C-y>'
  end
  return '<CR>'
end, { expr = true, silent = true })

vim.keymap.set('i', '<C-Space>', '<C-x><C-o>', { silent = true })

vim.schedule(function()
  require('mini.pairs').setup()
end)

return {
```
